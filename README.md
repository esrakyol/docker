# Docker Project

A web application built with Flask and Redis, running in Docker containers.

## Features
- Visitor counter using Redis
- Titanic dataset visualization
- Docker Compose setup with multiple services

## How to run
1. Clone the repository
2. Create a `.env` file with `REDIS_PASSWORD` and `REDIS_HOST`
3. Run `docker compose up --build`
4. Open http://localhost:4000
